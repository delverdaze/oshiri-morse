# 🍑 おしりモールス変換器

日本語を「お尻を叩く音」のモールス信号風テキストに変換し、SNS などにこっそり投稿するためのお遊びツールです。
受け取った人は、同じツールのデコード欄に貼り付けると元の意味が読めます。

公開ページ: [https://delverdaze.github.io/oshiri-morse/](https://delverdaze.github.io/oshiri-morse/)

```
長点 －  →  ﾊﾟｧｰﾝｯ‼︎   （バチーン！＝思いっきり叩く破裂音）
短点 ・  →  ﾌﾟﾘｯ        （ちょん♡＝かわいく軽く触れる音）
```

`🔊 おしりで聞く` ボタンを押すと、モールスのリズムに合わせて
**かわいい「ﾌﾟﾘ」と本気の「ﾊﾟｧｰﾝ」のギャップ**を音で楽しめます。
「ﾌﾟﾘ」と「ﾊﾟｧｰﾝ」には `assets/` に同梱した効果音（mp3）を使います。

例：「おしり」→ `ﾌﾟﾘｯﾊﾟｧｰﾝｯ‼︎ﾌﾟﾘｯﾌﾟﾘｯﾌﾟﾘｯ　ﾊﾟｧｰﾝｯ‼︎ﾊﾟｧｰﾝｯ‼︎ﾌﾟﾘｯﾊﾟｧｰﾝｯ‼︎ﾌﾟﾘｯ　ﾊﾟｧｰﾝｯ‼︎ﾊﾟｧｰﾝｯ‼︎ﾌﾟﾘｯ`

## 🛠 仕組み

### 1. かな → おしりモールス（変換コア）

実行時に AI は使いません。**和文モールス符号表をコード内に持ち、対応するかなを決定論的に変換**します。

1. 入力を空白で単語に分割
2. 各かなを和文モールス符号（`・` / `－`）に変換
3. `－` を `ﾊﾟｧｰﾝｯ‼︎`、`・` を `ﾌﾟﾘｯ` に置換
4. かな1文字ごとを全角スペース `　`、単語の間を ` ／ ` で連結

デコードは逆順で、`ﾊﾟｧｰﾝｯ‼︎` / `ﾌﾟﾘｯ` を `－` / `・` に戻して和文モールスを解読します。
対応するかな列は、符号の組み合わせが衝突せず一意に復元できます。ただし、漢字・カタカナ・小書きかななどの元の表記は復元できません。

- **カタカナ**は内部でひらがなに正規化
- **濁点・半濁点**は Unicode の NFD/NFC で分解・合成（例：`か`＋`゛`＝`が`）
- **長音「ー」「、」「。」**にも対応

### 2. 漢字 → 読み（前処理）

漢字混じりの文章は、エンコード時に [kuromoji.js](https://github.com/takuyaa/kuromoji.js) で形態素解析し、
各語の**読み（かな）**を取り出してから上記の変換コアに渡します。

```
好きです →（kuromoji）→ すきです →（変換コア）→ ﾌﾟﾘｯ… 
```

ページを開くと、リポジトリに同梱した辞書（約 17MB）を非同期で読み込みます（同一オリジン配信・外部CDN不使用）。読み込み中もひらがな・カタカナの変換はすぐ使え、読み込み後の変換処理はすべてブラウザ内で完結します。

### 3. 読みプレビュー

形態素解析は読みを誤ることがあります（例：「辛い」＝つらい／からい）。
デコード結果はひらがなのみで返るため、**送り手が投稿前に読みを目視確認**できるよう、
おしり化の前段の「読み（ひらがな）」を画面に表示します。読みが違う場合はひらがなで打ち直せば確実です。

### 4. 欧文（アルファベット・数字）の扱い

このツールの土台は**和文（日本語）モールス**です。ところが和文と国際モールスでは、**同じ符号でも意味が異なります**。

| 符号 | 和文モールス | 国際モールス |
|---|---|---|
| `・・・` | ら | S |
| `－－－` | れ | O |

そのため `・・・－－－・・・` をそのまま和文で読むと「られら」になり、SOS にはなりません。これを区別するため、アルファベットを含む入力では**欧文への切替マーカー**を前後に挿入します。

例：`SOS` → `[欧文開始] ・・・(S) －－－(O) ・・・(S) [欧文終了]`

デコード時はこの切替マーカーを読み取り、「以降は国際モールス表で解釈する」モードに入って復元します。数字も同様です。なお欧文は大文字小文字を区別しないため、復元はすべて**小文字**になります。

## ⚠️ 仕様上の制約

和文モールスは「音（かな読み）」単位の符号体系のため、以下は仕様です。

- カタカナは復元時に**ひらがな**になります（例：`モールス` → `もーるす`）。意味は通じます。
- **小書きかな**は大書きに統合されます（例：`きょう` → `きよう`）。和文モールスに小書き符号がないためです。
- **アルファベット（英字）と数字**に対応しています。アルファベットは欧文モールスに準拠し、かな・数字と混在して自動的に切り替え変換・復元が可能です。なお、アルファベットは復元時にすべて**小文字**になります。
- 漢字の読みは形態素解析の精度に依存します（読みプレビューで確認してください）。

## 🔒 プライバシー

入力テキストの変換はすべて利用者のブラウザ内で行われ、サーバーには送信されません。
